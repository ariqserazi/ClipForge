## ClipForge Project Instructions

1. This is a macOS Premiere Pro CEP extension.
2. Keep the extension name as ClipForge.
3. Do not use CP as an abbreviation.
4. Prefer simple vanilla HTML, CSS, JavaScript, Node child_process, and ExtendScript.
5. Keep the project manually installable in a classic CEP style.
6. Do not add heavy frameworks unless needed.
7. Make errors visible inside the panel.
8. Do not silently fail ffmpeg or Premiere import operations.
9. Keep code readable and beginner friendly.
10. Update README when install behavior changes.
